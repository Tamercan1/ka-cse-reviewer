# Dataset Auditing and Cleansing

When the user asks you to verify, audit, or review a large dataset (e.g., JSON banks of questions, synthetic data, large lists) generated by AI, follow these steps:

## 1. Scan for Conversational AI Artifacts
AI generation often leaks conversational thoughts into structured data. Always write a script to scan the dataset for the following common markers:
- `wait,`, `wait.`
- `actually,`
- `let me rewrite`, `let's change`, `let's fix`
- `contradiction`, `ambiguous`
- `as an AI`, `my apologies`, `my mistake`
- `let's look closer`, `let's figure out`

Extract the flagged items, review them manually, and write a patch script to clean the text so it sounds authoritative and professional.

## 2. Programmatic Validation over Manual Reading
If the dataset is large (e.g., >500 items), DO NOT attempt to read every item manually in the context window. Instead, write Python scripts to programmatically validate the domain logic:
- **Numerical/Math:** Use Regex to extract equations and `eval()` to verify the answers match.
- **Clerical/Sorting:** Extract lists of strings and use Python's `sort()` to verify alphabetical ordering answers.
- **Vocabulary/Definitions:** Cross-reference answer strings against dictionary JSONs or valid word lists.

## 3. Iterative Patching
Do not try to fix everything with terminal commands like `sed`. Write Python scripts that load the data, apply specific fixes to specific IDs/keys, and dump the updated JSON back to the file.
